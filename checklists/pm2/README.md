# ParaPlane PM-2 checklists

Draft checklists for the ParaPlane PM-2 powered parachute.

| File | Contents |
|---|---|
| [preflight.md](preflight.md) | Pre-flight inspection and engine start |
| [normal-ops.md](normal-ops.md) | Normal operating speeds and procedures |

## Status

Draft — based on general powered parachute practice, not validated against
the PM-2 POH. Verify all procedures against your aircraft's documentation
before flight. The pilot in command is responsible for airworthiness.

## Contributing

If you fly a PM-2 and find an error or missing item, please open an issue.
These checklists improve with real flight experience.
